# 源码阅读指南

文中的路径均相对于解压后的源码根目录。

## 整体调用关系

管理页面通过 `apps/console/src/lib/api` 调用后端接口。后端在 `apps/server/src/router.ts` 挂载各业务路由，从认证会话解析当前账号，再结合工作区、角色和数据归属查询数据库。

外呼任务由后端调度器选择号码、检查容量并冻结当前配置，随后交给 Go 语音桥。语音桥连接 FreeSWITCH 与模型 / TTS，负责音频播放、识别事件、打断和挂断；事件回传后端，落入任务、通话记录和费用相关数据。

## 多人使用与权限

先读 `apps/server/src/modules/workspace/company-policy.ts`，了解三个固定角色及工作区 / 本人数据范围；再读 `company-access.ts`，看有效成员读取、员工筛选和通话可见范围如何落到查询条件。

客户授权与通话归属不同，相关处理也在 `apps/server/src/modules/crm` 中。不能只改菜单显示就认为权限已经调整。修改配置时使用 `config-revision.ts` 中的版本比对，避免多人同时保存互相覆盖。

话术写权限集中在 `apps/server/src/modules/agent/script-access.ts`。发布版本和个人使用配置的衔接分别看 `agent.release.ts`、`personal-agent-config.ts`，并追踪调用方的工作区参数。

## 外呼调度与容量

从 `apps/server/src/modules/telephony/sip.worker.ts` 的 `tick` 开始。它检查维护开关、供应商就绪、容量、任务和线路，在事务中确认状态后再派发。

`task-fair-queue.ts` 负责按任务权重选择下一项任务；实际调度进度写入由工作器完成。`task-parallelism.ts` 负责倍数、任务槽位和线路槽位相关检查。

每秒起呼速率、同时通话容量、任务并发、线路并发和 FreeSWITCH 会话配置属于不同约束。部署时以新环境实际参数为准，源码默认值不能代替线上运行配置。

## 一通电话的人物声音与录音回答

`recording-selection.ts` 先选本通开场人物，`call-voice-configuration.ts` 合并该人物的调教和合成配置，`script-recordings.ts` 核对可用资产并冻结到本通配置。

Go 的 `internal/provider/direct_recording.go` 负责客户问句到录音的匹配：规范化后的完整问句必须命中当前配置的问法。未匹配、冲突、音频缺失或读取失败时进入模型回答路径。页面上编辑相似问法与实际通话使用的快照，应沿这条链路一起看。

## 回复、TTS 与打断

`services/sip-bridge/internal/provider/realtime.go` 管理实时模型事件；`cosy.go` 把模型文本交给复刻音色合成器，`flushText` 负责提交文本分片。

`internal/aicall/session.go` 协调线路、模型和播放。轮次与代次标识用于区分当前回复和已经取消的旧回复。调整打断时，需要同时看模型取消、音频队列和实际已播放进度。

`internal/media/g711.go`、`resample.go` 处理编码与采样率；`internal/voice/rtp.go`、`jitter.go` 处理媒体包与播放时序。模型文本结束、TTS 生成结束和电话端音频播放结束是三个不同时间点。

## 礼貌告别与自动挂断

先读 `services/sip-bridge/cmd/bridge/followup_ending.go`。该状态机核对客户是否仍在说话、识别是否待返回、结束语属于哪个轮次，以及音频是否已经播放，再返回等待、补短告别或挂断动作。

`reply_review.go`、`invitation_acceptance.go`、`dialogue.go` 提供业务判断，最终在 `main.go` 与会话事件衔接。排查“说了再见但没挂断”时，应沿业务判断 → 当前轮次 → 播放完成 → 挂断控制检查。

## 单通电话费用

`apps/server/src/modules/billing/call-costs.ts` 用本通派发线路的历史单价和接通时长计算电话费用，再汇总关联的模型用量。分钟计费采用向上取整；缺少时长、单价或模型用量时保留待核算原因。

该文件给出的模型费用有明确的估算与待核算状态。账单同步和供应商实扣要继续查看 `aliyun-bill.service.ts` 等账单链路，不应把估算值直接解释为钱包实扣。

`apps/server/data/billing-rates.json` 是程序自带的费率目录，包含版本和币种；不代表所有当前线路和阿里云调用的实际单价。
