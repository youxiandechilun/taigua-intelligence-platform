# 平台登录与员工隔离

每位员工继续用原网页和系统账号。首次进入“系统设置”下载 Windows、Mac Intel 或 Mac Apple 芯片执行插件，解压并首次打开后自动关联，无需填写地址或点击连接。

普通平台登录、账号检查、同步和发布在员工电脑执行。平台登录窗口在员工电脑打开，员工本人扫码或完成短信验证，成功后保存到自己的工作目录；普通登录不上传 Cookie。

定时任务需要服务器素材与有效授权。任务中心显示“已就绪”后，员工电脑可以关机。如果本机授权无法在服务器通过核验，可在账号登录弹窗选择“服务器定时授权”，完成真实平台页面中的登录。YouTube/Google 登录必须在员工电脑插件中使用系统 Chrome 或 Edge 完成，服务器不会启动 headless Google 登录；完成本机登录后，定时授权仍可同步到服务器。

每位员工的数据目录、数据库、平台 Cookie、素材、草稿、任务及登录会话隔离。员工只操作自己的工作区，管理员可以切换工作区管理。切换后旧标签页的写入和旧登录画面操作会被拒绝。

同一员工的任务依次执行，不同员工可以同时执行。普通任务和服务器定时任务均已取消全站并发数量上限，旧手动上限和自动容量计算不再生效；实际运行仍使用所在电脑或服务器的资源。

新素材默认保存在员工电脑，服务器保存索引；原有服务器素材按需缓存。明确删除本机素材时，先清理本机文件，再凭可补报回执清理服务器索引与定时副本。

取消、启动失败、浏览器关闭和工作进程退出会释放该员工的执行占位。结果不明时保留待核对状态，不自动重复发布。平台额外验证需员工本人完成，合成浏览器测试不代表真实账号或真实发布已经验收。
