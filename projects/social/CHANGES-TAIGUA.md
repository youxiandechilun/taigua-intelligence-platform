# 泰卦部署改造说明（2026-11-09）

海外授权与账号归属修复（2026-11-11，插件 2026.11.11.3）：

- 修复 Facebook 把访客页面保存为登录成功的问题；八个海外平台统一要求平台域名、未过期登录凭据和可见账号入口，安全验证未完成时继续等待。
- 平台网络、页面加载和安全验证异常返回“暂未确认”，保留原账号状态；发布前检查可重新检测，未确认时不继续发布。
- TikTok、YouTube 只在海外账号显示，海外入口复用原编号、完整发布配置和浏览器实现，删除重复配置；不迁移或删除业务账号。
- 登录导航在页面开始响应后即可继续；确认账号入口后不再重复固定等待和 networkidle，日志分别记录浏览器启动与平台响应耗时。
- Threads 入口同步为官方现行域名，检测仍兼容旧域名导出的授权。依据：https://about.fb.com/news/2025/04/new-features-threads-web-experience/
- 验证仅使用合成会话和隔离数据；未冒充真实平台账号登录或真实发布验收。

海外登录修复（2026-11-11，插件 2026.11.11.2）：

- 新安装包包含八个海外平台适配器；旧插件缺少新增平台时，登录弹窗直接提示从系统设置更新。
- 本机登录兼容 JSON 启动错误、SSE failed/message 及断流，不再统一显示“未取得有效授权”。
- 国内、海外的添加与重新登录共用完成流程：确认授权保存并同步账号后自动关闭弹窗、返回并刷新账号列表；引导同步更新。
- 视频历史平台筛选、海外标识、设置平台清单和发布前检查映射补齐；平台接入状态仍明确保留真实账号待验收边界。

基于 QianFan-Sync 提交 ca9d9fae8f61f6115513d5d25ede19d39c0b1ac2 改造。
原许可证和源代码中的版权声明保留；页面不再展示原作者推广、赞助和外部反馈入口。

- 页面沿用原布局，仅将主题色改为现有电销系统的红色、黑灰色及对应浅色。
- 新增账号密码登录、管理员员工管理、停用、重置密码、本人修改密码和退出。
- 每位员工拥有独立数据库、Cookie、素材、草稿及发布队列；管理员通过工作区切换管理。
- 登录会话由服务端管理；写请求校验 CSRF；旧工作区请求、路径越界和匿名访问被拦截。
- 服务端使用官方 Playwright Chromium 无头浏览器，不自动申领原浏览器供应商的许可证。
- 普通发布、平台登录、账号检查与素材处理在员工电脑执行；定时任务准备完成后由服务器执行。同员工串行、不同员工并行，已取消全站并发上限。
- 新增和修改代码使用中文注释标明改造用途。
- 使用用户提供的泰卦品牌图；管理员可在“系统设置 → 系统 Logo”上传、预览、保存或恢复默认，全部员工共用。自定义图片保存在共享状态目录，服务重启和前端更新后保留；只接受校验后的 PNG/JPG/WebP，最大 5 MB。
- 服务器平台登录在弹窗中展示真实浏览器页面，支持扫码、点击、拖动与受限文本输入；添加账号和过期账号重新登录共用此流程。取消、断线、异常和超时均回收浏览器，登录方式切换不再被抖音、小红书误判为成功。YouTube/Google 登录改由员工插件启动本机系统 Chrome 或 Edge，避免 Google 拒绝自动化浏览器；定时发布仍使用已同步的授权。
- 登录画面及操作会话只存在于对应员工工作进程，仍经过网关认证、CSRF 和工作区校验；跨员工任务编号不能控制对方页面。
- 服务器补齐官方 Noto CJK 中文字体，部署依赖及检查脚本一并更新，避免平台登录页出现方框字。

部署目录：`/opt/taigua-publish`。仅网关监听 `127.0.0.1:18870`，Nginx 对外提供 HTTPS。
`deployment/prepare_remote.py` 准备依赖；`deployment/activate_remote.py` 备份并切换域名。
员工停用会撤销设备并停止其服务器进程；任务持久化保存。未执行任务继续排队，结果不明的任务显示待核对，不自动重发。

新增可持久化的员工浏览器调度队列，取消全站并发上限。删除旧上限设置、自动容量预算和页面限制展示；旧配置不能恢复数量限制。
删除旧全站单文件锁调度，登录、同步发布和持久化浏览器入口共用员工串行队列；不同员工可同时运行。

验证范围：账号权限、真实工作区草稿与素材隔离、平台登录会话隔离、真实浏览器页面及输入往返、取消后释放员工占位、员工顺序排队、多员工无全站数量限制、进程崩溃回收、独立浏览器保存与恢复登录状态，以及前端构建。
尚需使用真实平台账号验证扫码、账号状态以及各平台发布结果；部署测试不执行真实发布。

混合执行更新：

- Windows x64、Mac Intel、Mac Apple 芯片插件自带 Python。下载后首次打开自动关联员工，登录电脑自动启动，无需填写地址或点击连接。
- 新素材原文件直接保存在当前员工电脑；服务器保存索引，原有云端素材按任务自动缓存。定时仅同步引用文件和授权，服务器校验后显示已就绪，此后员工电脑可以关机。
- 设备鉴权、一次性激活、员工隔离、持久化领取、结果补报和终态回执处理保持独立；断线不重复发布。
- 视频、图集、文章草稿都按账号拆分并进入同一持久队列；普通账号导入在本机完成，公开资料同步回服务器。
- 删除已替代的 BrowserPoolSettings 组件，保留定时仍在用的服务器浏览器与调度。安装包去除重复 FFmpeg 二进制与开发数据，保留许可证。
- 发布、账号、素材、草稿、设置和任务中心补齐新手引导，升级版本后旧用户也能看到新增说明；明确区分入队、就绪和完成。
- 本机素材删除进入员工串行队列，确认本机原文件清理后再同步删除索引和定时副本；回执支持幂等补报。
- 任务中心补齐侧栏、设置页和路由入口，使用统一持久队列，删除未使用的旧内存任务列表及重试入口。
- 任务中心只展示任务列表、进度和结果，空列表显示“暂无任务”；插件安装提示、下载入口和设备状态仅在系统设置展示。
- 素材名称可直接点击原位编辑，回车或失焦保存、Esc 取消；名称按员工保存，旧插件同步不会覆盖，原文件及任务引用不变，无需重新安装插件。
- 抖音视频、图集改为按可见的标题与正文编辑框定位，兼容旧版布局和延迟渲染；写入后校验内容，移除固定父级 XPath 及 Mac 不兼容的全选逻辑。历史定位超时先显示中文原因，并保留原始诊断。

验收边界：合成平台验证不向真实平台发帖；各平台扫码、额外验证及真实发布效果需员工本人核验。Mac Intel 可在本机验证内置运行环境，Windows 与 Mac Apple 芯片安装仍需对应机器实测。正式部署结果记录在 deployment-result.json。

插件入口与页面修正：

- 删除系统设置中的“本机插件与服务器定时”标题和执行方式说明，保留下载、设备状态及必要操作。
- Mac 安装包外层只展示“泰卦插件.app”；Windows 外层只展示“泰卦插件.exe”。运行环境、源码、关联信息及许可证封装在应用内部，移除旧的外露命令脚本和说明文件。
- 双击后显示准备进度与真实连接状态；首次关联、浏览器准备、网络中断和启动失败都有中文提示，过期心跳不会继续显示在线。
- 任务中心补齐与其他业务页面一致的左右边距和窄屏布局，标题、引导按钮和任务列表不再贴边。
- 新手引导按单一应用入口更新。员工隔离、素材目录和已有任务引用沿用原机制。
- 补齐插件漏带的微博静态分类配置；使用包内解释器和包内后端验证平台注册、本机工作进程及合成发布链路。

Mac 兼容性修复（2026-11-11）：

- Mac Intel 与 Apple 芯片插件最低系统统一为 macOS 13.0；修正原先误设为 14.0 的应用声明和依赖解析平台。
- 将 NumPy 2.2.6 的 macOS 14 专用二进制换成同版本兼容构建，清理旧二进制；兼容补丁保留原插件业务源码和员工隔离机制。
- 构建时检查每个 Mach-O 架构与最低系统要求，不允许仅修改应用声明掩盖依赖不兼容。
- 本机 macOS 13.7.8 Intel 验证应用启动服务、Tk 窗口、NumPy/OpenCV、浏览器、FFmpeg 和本机工作进程；Apple 芯片包通过静态检查，尚无对应实体设备实测。
